## 修复（1.3.1）

### 点进「通知」白屏

根因：通知页在**画界面之前**就 `await` 了三个原生调用（权限、精确提醒、待发送条数）。Capacitor 的桥在某些情况下 Promise 一直不 settle（插件没注册好、系统设置页没返回、WebView 刚起来），`await` 就永远挂着 —— 面板已经切过去、却一帧都没画，用户看到的就是纯白。

改成**先画后补**：

- 界面只用本地已存的设置同步渲染，原生信息先显示「正在读取…」
- 三个原生查询并行补，每个都带 4 秒超时；超时就写「暂时读不到系统通知权限」这类人话，而不是永远转圈
- 权限请求、打开「闹钟和提醒」也各带超时（60 秒），点开关不会再出现「点了没反应」
- `switchPanel` 里数据没就绪就直接返回的分支，对通知页开了例外（它不依赖今日数据），不会再切出一片白

### 任务勾选框变成长方形

根因：手机断点里有一条 `button { min-height: 44px }`（触摸目标）。任务勾选框自己就是 `<button class="task-check">`，`height: 24px` 被 `min-height: 44px` 压成 24×44 的竖条；微习惯的 `.habit-check` 是 `<span>`，所以没受影响 —— 这正是你看到的「任务变长方形、微习惯正常」。

修法：把 `min-height / max-height / width / height` 全部写死成 24px，并用 `button.task-check` 提高优先级；尺寸、圆角、边框色、勾选填充色与微习惯完全一致。
