## 通知（Android）

- **修复每日提醒的重复周期**：原来用 `{ at, repeats: true }`，Capacitor 会把「保存时刻到触发点」当成重复间隔 —— 早上 8 点保存 9:00 的提醒会变成每小时响一次。现在改用日历式 `{ on: { hour, minute }, repeats: true }`。
- **点开关就有反应**：打开任一开关立刻请求系统通知权限（之前只在保存时才要权限，点了像没反应）。
- **新增「发送测试提醒」**：5 秒后到达，点它应该回到复盘页 —— 用来判断问题在权限/渠道，还是排期逻辑。
- **新增「让提醒更准时」**：Android 12+ 的「闹钟和提醒」权限，不再自动跳系统设置；不给也能用，只是可能晚几分钟。
- **点通知回到对应页面**：复盘提醒→复盘、任务提醒→任务并打开该任务、对话里安排的提醒→AI 对话；冷启动时先记下目标，首轮数据到位后补跳。
- 新增高重要性通知渠道 `msa-reminders`，提醒会以横幅弹出，不再静默落进通知栏。

## 网站与 App 一致性

- 之前通知模块在文件顶部静态 `import '@capacitor/core'`：APK 打包后正常，但零构建的网站会直接白屏（浏览器解析不了裸模块名）。现在统一走 `src/native.js`（运行时全局 + 函数内 `await import(...)`），网页端自动降级为「仅在 App 内可用」。
- `tools/check.mjs` 增加硬规则：`src/` 下出现静态裸模块导入就失败。

## 任务 = 微习惯的勾选框

- 任务卡片与微习惯统一勾选框：同尺寸、同圆角、同填充色，点勾即完成/取消完成（之前已落地，这次把视觉与样式也统一，并修掉已完成任务只变淡不划线的观感问题）。

## 自动检查更新

- 启动时每天最多查一次 GitHub Releases；有新版就在 Wi-Fi 下用系统 DownloadManager 下载，点「安装更新」走系统安装器覆盖升级，数据保留。
- 另有 WorkManager 每日后台检查（24 小时一次），不开应用也会查。
- 设置页显示当前版本、发现的新版本、下载进度与安装入口。

## 验证

- 新增 `tools/notification-test.mjs`：用假插件抓排期参数，断言每日用 `on`、任务用 `at`、网页端不碰原生接口。
- `npm run check` / `tool-audit` / `action-routing-eval` / `update-test` / `notification-test` 全绿；DOM 测试新增 3 条通知页断言并通过。

## 怎么确认自己装的是这一版

**设置 → 版本**：显示 `My Study Agent v1.3.0（Android App）`。

这一行是专门加的 —— 之前无法在应用里看版本，只能靠数左侧导航有几项去猜。**只有 6 项导航（AI 对话/任务/复盘/学习/日志/生活导航）说明装的是通知功能之前的旧构建**，本版是 7 项，最后一栏是「通知」。

同时把手机抽屉导航改成可滚动：7 项在横屏/矮屏上会超出容器高度，最后一项可能被裁掉，看起来就像"没有通知入口"。
